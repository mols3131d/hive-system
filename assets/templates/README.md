# Workspace Templates

Copy only applicable templates into the explicitly selected data workspace; never save actual records in the system repository. These are optional authoring sources, not authoritative instructions or permissions. Replace placeholders and remove comments, unused sections and invented defaults before saving records. The [workspace guides](../../docs/policies/workspace/README.md) own the actual rules. Follow the [frontmatter contract](../../docs/policies/workspace/frontmatter.md) for required, conditional and optional fields. Optional fields are omitted by default, except a known artifact kind.

| Template | Use |
| --- | --- |
| [scope-readme.md](scope-readme.md) | Project or reserved-scope navigation README for tasks or directives |
| [task.md](task.md) | Work bundle README: goal, acceptance and references |
| [directive.md](directive.md) | Project or scope direction, applicability and provenance |
| [bot.md](bot.md) | Canonical bot identity and purpose in `SOUL.md` |
| [memory.md](memory.md) | Latest Bot memory (`MEMORY.md`), durable scoped memory or topic note |
| [artifact-manifest.md](artifact-manifest.md) | Group related outputs and provenance |
| [message.md](message.md) | Optional retained directed message when needed |
| [session-context.md](session-context.md) | Optional selected resumption checkpoint |
| [report.md](report.md) | Human-facing artifact in its owning work or standalone |
| [research.md](research.md) | Research question, evidence and open checks |
| [review.md](review.md) | Review criteria, findings and disposition |
| [work-note.md](work-note.md) | Focused working observations |
| [handoff.md](handoff.md) | Focused continuation handoff, often sufficient on its own |
| [bundle-readme.md](bundle-readme.md) | Document bundle entrypoint |
