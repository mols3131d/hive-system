# Policies

Use this area for **adopted, cross-cutting project policies** that need their own durable explanation, such as a language or disclosure policy. Add a policy document only when the derived project has actually chosen that policy.

## Hive workspace policies

Use the [Hive workspace contracts](workspace/README.md) for data ownership, agent responsibilities, record formats, authority, retention and publication in user-controlled workspaces. The system repository's own development and Git rules remain separate. No live workspace records belong here.

Before adding a policy, check whether its rule already belongs to [Development](../development/README.md), [Tools](../tools/README.md), or executable configuration. Link to enforcement rather than duplicating it.
